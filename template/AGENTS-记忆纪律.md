# 记忆纪律（粘进你的 AGENTS.md 或系统提示词）

> 插件只提供工具和文件结构；**让记忆不烂的是这段纪律**。没有它，三个月后你的记忆库会变成一座屎山。

## 开场（每个新会话，先做这几件，别先问）

1. 读 `memory\身份.md`（天性层：它是谁、怎么说话、底线）
2. 读 `memory\待办.md`（现在该做什么）
3. 读 `memory\近况.md`（他在哪、在干嘛；先看"最后更新"是否超过 6 小时）
4. 话题具体时先 `memory_tree` 看那一枝的标题，再决定翻哪条；要正文才 `memory_get`

读完直接接上话，**不要汇报"我读了什么文件"**。

## 检索（三层：目录 → 枝页 → 全文，越往下越贵）

- `memory_search "关键词"`：只回「枝 › 标题」+ id，不吐正文
- `memory_tree <枝名>`：那一枝的标题清单
- `memory_get <id>`：才给全文 —— **翻一次 = 记一次 access**，这就是沉浮信号，别跳过

**什么时候必须搜，不靠"想起来"**：
1. 他提到"上次 / 之前 / 那件事 / 某个项目 / 某个人" → 先搜再答
2. 要做判断、写长东西、给建议之前 → 先搜相关条目
3. 搜不到才是真没有

## 写（每轮回复发出前自检一次，不攒）

这轮有没有"以后会用上 / 找不到会出事 / 他明确让记"的新事实？有就当场 `memory_add`，别等会话结束。

写前自问三条：
1. 这条以后会被"用上"吗（不是"它发生过"）
2. 找不到它会不会真出事
3. 他明确让记的 → 直接写

**待办不写条目流**（写 `待办.md`）；**工作过程不写**（那是日志的事）。

## 收尾（每轮办完事顺手做）

- 挑 0~3 条写进条目流
- 他说过不对/过时的旧条目 → `memory_feedback --bad`；确认过的 → `--good`
- 位置变化当场改 `近况.md`

## 别做的事

- 不手改 `干.md` / `目录.md` / `枝\*.md`（生成物）
- 不手改 `条目.jsonl`（唯一真相，只通过 `memory_add` 写）
- 不把私事写进会外发的地方（条目有 `visibility`，默认 private）
